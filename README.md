### **API Weather Application**

Developed by Raven Blessinger 



#### Overview 

This program developed with Python allows a user to retrieve the current weather for a city 

with Open-Meteo APIs. The program prompts the user for a city name, then displays location

information, time, temperature, humidity, weather conditions, and a weather summary. It also

displays recommended activities for the day based on current weather conditions.



#### Skills Exhibited

* Python programming
* Conditional statements
* Loops
* Exception and error-handling
* API integration
* JSON data parsing
* Dictionary structures
* Data and string formatting
* Program documentation
* Third-party library usage



#### Features

* Searches for weather based on best-match city name
* Automatically handles coordinate retrieval with Open-Meteo geocoding API
* Automatically handles forecast retrieval with Open-Meteo weather API
* Displays location information and displays relevant forecast information
* Allows users to complete multiple searches during their session
* Includes input validation and error-handling for network requests



#### Requirements

* Python 3.11 or newer
* Internet connection
* requests package for Python



#### APIs Used

* Open-Meteo Geocoding API
* Open-Meteo Weather Forecast API
